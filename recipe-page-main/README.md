## My process

I first started with the HTML part of the project thinking about how to structure the page. at the end I opted to create a main container and then put the recepi inside an article tag. next, I added the styles for the page. when I finished the page, I realized I could have done the whole thing with grid. but since this is my first time doing this kind of thing, I will leave like this for now.
